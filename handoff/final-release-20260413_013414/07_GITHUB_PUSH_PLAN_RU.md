# Что именно сохранить в GitHub

Сохранять в GitHub нужно не хаотично, а как control-layer.

## Рекомендуемая структура в repo
`handoff/final-release-<DATE>/`

Внутри:
- 01_FINAL_PROJECT_STATUS_RU.md
- 02_ACCESS_INVENTORY_RU.md
- 03_RELEASE_BLOCKERS_AND_DECISIONS_RU.md
- 04_NEXT_CHAT_MASTER_PROMPT_RU.txt
- 05_DONE_PERCENTAGES_RU.md
- 06_WHAT_IS_MISSING_FROM_YOU_RU.md

## Почему так
Это позволяет:
- не терять контекст при новом чате
- не смешивать handoff с кодом приложения
- держать отдельно control-layer
