# SIGNALUM Voice AI Portal

## Основа
Новый продуктовый вектор: voice-first корпоративный портал уровня Discord для российского рынка.

## Ядро продукта
- постоянные голосовые комнаты;
- чаты и треды вокруг комнат;
- online presence и быстрый вход в звонок;
- live transcript;
- room assistant и personal assistant;
- knowledge / RAG / action layer;
- control-plane и GitHub/VPS governance.

## Принцип
Сначала стабильное realtime voice/messenger ядро, затем AI-надстройка, затем market hardening.

## Ближайшая цель
Собрать новый каркас продукта в структуре monorepo:
- apps/web
- apps/api
- packages/ui
- packages/shared
- ai-config
- infra
- evals
- docs
