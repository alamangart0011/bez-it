# CorpChat V17 — этап 1 / русский UI и shell

## Что изменено

- Убраны англоязычные заголовки и подписи из shell, входа, профиля, голоса и админки.
- Добавлена тёмная тема по умолчанию и светлая тема как опция с сохранением в localStorage.
- Левая панель усилена: русский бренд-блок, поиск, навигация, список комнат, мини-профиль и быстрый переключатель темы.
- Правая панель стала контекстной: отдельно для текста, голоса, собрания, профиля и центра администратора.
- Добавлен отдельный маршрут `/app/meetings/:roomId` и экран комнаты для собраний.
- Центр администратора переведён из простого журнала в единый обзорный экран.
- Для shell добавлены backend endpoint'ы `GET /api/rooms/:roomId` и `GET /api/admin/overview`.

## Что сознательно оставлено на следующие этапы

- забыли пароль / приглашения / управление сессиями;
- полноценные профили сотрудников и настройки;
- живая ролевая матрица и операции администратора;
- полноценная модерация голоса и собраний.
