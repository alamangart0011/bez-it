# Stage 9 — Launch control / системные объявления / массовая модерация

Что добавлено:
- системное объявление прямо в shell для всех, админов, голоса или собраний;
- массовая голосовая модерация: mute all, unmute all, lower all hands, stop all screens, disconnect all;
- обновлённый SQL-шаг `008_launch_control.sql` для existing baseline.

Что это даёт:
- можно быстро донести до пользователей важный режим работы, регламент или срочное предупреждение;
- ведущий или администратор может быстро стабилизировать комнату на большом созвоне без ручного перебора каждого участника;
- контур остаётся в том же shell и не расползается в отдельную панель.

Что проверить на живом домене:
1. Опубликовать системное объявление из вкладки «Система».
2. Убедиться, что banner появился в shell у обычного пользователя.
3. Зайти в голосовую комнату 3–5 пользователями.
4. Проверить `Отключить всем микрофоны`, `Опустить все руки`, `Вывести всех из голоса`.
5. Проверить аудит по действиям `admin.announcement.*` и `voice.*_all`.
