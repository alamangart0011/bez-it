# Stage 10 / Контролируемый вход и присутствие

Что добавлено:
- режим входа в голосовую комнату: свободный вход / вход по запросу;
- очередь запросов на вход для ведущего и модератора;
- одобрение и отклонение запросов без выхода из VoiceRoomPage;
- адресное уведомление сотруднику о решении по запросу;
- счётчики заявок в комнате;
- блок посещаемости в комнате для собраний.

Практическая цель:
- безопасно заводить большие команды в голос и собрания;
- не пускать всех сразу в чувствительные комнаты;
- показывать ведущему, кто ещё не подключился к голосу собрания.
