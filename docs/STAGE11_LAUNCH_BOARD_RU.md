# Stage 11 / Launch Board + Presence Journal

Что добавлено:
- launch-board в административном обзоре;
- журнал присутствия по комнатам собраний;
- быстрые действия ведущего по собранию;
- миграция `010_launch_board_presence.sql` для existing baseline.

Что проверять на живом контуре:
1. Открыть комнату собрания.
2. Войти в голос и выйти из голоса несколькими сотрудниками.
3. Убедиться, что журнал присутствия фиксирует события.
4. Ведущему выполнить быстрые действия: открыть собрание, отключить всем микрофоны, сбросить руки, остановить экраны, завершить собрание.
5. В админ-центре проверить launch-board: активные голосовые комнаты, очереди входа, собрания.
