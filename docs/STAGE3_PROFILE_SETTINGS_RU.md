# CorpChat V17 / Этап 3

Закрыто в этой редакции:
- отдельный модуль профиля сотрудника;
- `GET /api/me` с расширенными данными профиля, комнатами, активными сессиями и настройками;
- `PATCH /api/me` для обновления ФИО, должности, телефона, статуса и описания;
- `GET /api/me/settings` и `PUT /api/me/settings`;
- таблицы `user_profiles`, `user_settings`, `departments`;
- экран `Настройки` с блоками уведомлений, внешнего вида, голоса и доступности.

Практический результат:
- профиль перестал быть декоративной карточкой;
- сотрудник управляет своими данными и персональными настройками в отдельном контуре;
- тема, уведомления и голосовые параметры сохраняются на backend.
