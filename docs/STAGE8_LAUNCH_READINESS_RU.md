# STAGE 8 / Launch readiness

Что усилено:
- вызов сотрудника в голосовую комнату или комнату собрания;
- счётчики участников и активного голоса прямо в списке комнат;
- личный канал сокета `user:{id}` для адресных событий;
- фиксация релизной метки через корректный `system_settings.value_json`;
- отдельный SQL-шаг `007_launch_readiness.sql` для живой БД baseline.

Что проверять перед понедельничным показом:
1. Комната открывается без ошибки.
2. Модератор видит кнопку `Вызвать в комнату`.
3. У вызываемого сотрудника появляется баннер с быстрым переходом.
4. Счётчики `в голосе` и `участников` отображаются в левом списке комнат.
5. `deploy/apply_sql.sh` прогоняет все SQL-файлы по порядку.
