# Domain information contract — room-based V17

## Цель

На домене `https://ai.voice.oboron-it.ru` пользователь после входа должен видеть рабочую информацию, а не технический шум или пустой экран.

## Что обязательно должно быть видно на домене

### 1. Shell
- room tree
- активная рабочая зона
- контекст справа
- компактный профильный блок

### 2. Dashboard
- активные комнаты
- кто сейчас в голосе
- текущие собрания
- заявки на вход
- инциденты
- быстрые переходы

### 3. Text room
- заголовок комнаты
- участники
- лента сообщений
- composer
- files / pins / context

### 4. Voice room
- статус комнаты
- список участников
- one-click вход в голос
- локальное состояние
- компактные moderator controls

### 5. Meeting room
- статус
- ведущий
- участники
- повестка
- материалы
- журнал
- итог

## Что не должно доминировать на домене
- debug strip
- service / release шум
- пустые summary карточки
- self-description сборки
- тестовые или архивные хвосты в обычной выдаче

## Критерий приёмки

Домен считается информационно нормализованным, если:
- пользователь видит полезную рабочую картину сразу после входа
- shell не пустой
- dashboard работает как диспетчерская
- voice и meeting читаются как product-first сценарии
