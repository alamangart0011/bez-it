# Browser acceptance checklist

Порядок проверки на живом домене https://ai.voice.oboron-it.ru

1. Логин под admin@corpchat.local
2. Проверка shell: левая панель, список комнат, верхняя панель, переход в админку
3. Открытие текстовой комнаты: список сообщений, composer, правая панель
4. Отправка текстового сообщения
5. Открытие голосовой комнаты
6. Нажатие Войти в голос
7. Разрешение микрофона
8. Проверка mute / unmute
9. Проверка deafen / undeafen
10. Открытие комнаты собрания
11. Проверка admin center: обзор, пользователи, комнаты, система
12. Если есть ошибка, фиксировать:
   - URL страницы
   - текст ошибки на экране
   - Console error
   - Network request с кодом ответа
