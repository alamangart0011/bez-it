# Сценарии запуска нового чата

## Сценарий: только статус
Использовать, если нужно быстро понять состояние проекта без изменения кода.

## Сценарий: recovery
Использовать, если есть runtime, schema или deploy-ошибка.

## Сценарий: дизайн
Использовать, если нужен UX/UI/branding без смены продуктового канона.

## Сценарий: release
Использовать, если нужно готовить baseline к выкладке, smoke и post-check.

## Сценарий: код
Использовать, если нужно менять backend/frontend/deploy/sql внутри active baseline.

## Главное правило
Сначала выбрать сценарий, потом действовать по нему. Не смешивать все режимы в один хаотичный поток.
